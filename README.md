# 왕 죽이기 (Kill The King)

왕 뒤에서 몰래 칼을 들다가, 돌아보면 시치미 떼는 한 손가락 눈치 게임.

**바로 하기: https://kwangmin88.github.io/kill-the-king/**

- 화면을 누르고 있으면 칼을 들고 게이지가 찹니다. 왕이 돌아보면 손을 떼세요.
- 왕이 되면 누를 때 뒤를 돌아봅니다. 뒤따르는 자의 게이지가 빨개졌을 때 돌아보면 감옥으로 보냅니다.
- 감옥에 보낸 수가 기록입니다.

`index.html` 한 장이 게임 전부입니다(three.js 와 모델이 안에 들어 있습니다).

## 쓴 것
- 3D 인물·성 소품: KayKit Adventurers · Dungeon Remastered — Kay Lousberg (CC0)
- 왕관: Quaternius Crown (CC0)
- 효과음: Kenney Impact Sounds (CC0)
- 제목 글꼴: Black Han Sans (SIL OFL 1.1)

놀이 방식은 Studio Seufz 의 MURDER(2014)에서 따왔습니다.
